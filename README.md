# 又松大學校友通訊編輯器

GitHub Pages 單頁應用（`index.html`）。介面為繁體中文、韓文、英文。

資料只存在這台電腦瀏覽器的 **localStorage**。沒有帳號、沒有雲端協作、沒有 AI。換電腦或清除瀏覽器資料前，請用 **JSON 備份／匯入**。

## 這次調整

- 排版第一步改為校友期刊 **A–D**（溫暖敘事、現代連結、專業成長、同行未來／따뜻한 이야기、현대적 연결、전문성과 성장、함께하는 미래）。其餘版型收在「更多版型」。
- 示範內容改為**校友通訊**（학교 동문／校友），不再使用就業支援中心範本。預設校名 Woosong University、主標 ALUMNI、海軍藍與青色報頭，並建議上傳校徽。
- 匯出頁加上校對清單、超出 A4 與缺少校徽的匯出前提醒，以及微信精簡版（單欄 HTML）。A4 的 PDF、PNG、Canva PPTX 仍在。
- 基本資料可記「配對版本備註」。韓文版與中文版是兩份獨立文件。

已經存在瀏覽器裡的舊稿不會被自動覆蓋。要改用新的校友示範，請在基本資料按「重設示範內容」（建議先匯出 JSON）。

## 정기 1쪽을 시작하는 방법

1. 편집기를 연다. 처음이면 동문 예시(우송대학교 동문, 제목 ALUMNI)가 나온다.
2. ① 기본 정보에서 월·연도·호수를 고치고, 우송대학교 로고를 올린다. 중국어판이 있으면 짝 판본 메모만 적는다.
3. ② 레이아웃에서 A–D 중 하나를 고른다. 정기 1쪽 예시는 B 현대적 연결(2단)이다.
4. ③ 콘텐츠에서 예시 문장을 실제 동문 소식·행사로 바꾼다. 한 쪽을 넘으면 빨간 테두리가 뜬다.
5. ④ 내보내기에서 교정 목록을 확인하고, 로고·넘침 안내를 본 뒤 PDF를 저장한다. 중국어 독자용으로는 위챗 요약본(HTML)을 따로 받는다.

배포：GitHub Pages → `main` / root.
